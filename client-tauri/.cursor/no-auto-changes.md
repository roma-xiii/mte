# Правило: Запрет автоматических изменений

## Основное правило
AI ассистент НЕ ДОЛЖЕН самостоятельно изменять, создавать или удалять файлы без явного разрешения пользователя.

## Разрешенные действия
- ✅ Читать файлы (Read tool)
- ✅ Искать в коде (Grep, Glob tools) 
- ✅ Просматривать структуру проекта
- ✅ Давать советы и рекомендации
- ✅ Показывать примеры кода в сообщениях

## Запрещенные действия без разрешения
- ❌ Изменять файлы (StrReplace, Write tools)
- ❌ Создавать новые файлы
- ❌ Удалять файлы
- ❌ Изменять конфигурационные файлы
- ❌ Устанавливать новые библиотеки (npm install, yarn add)
- ❌ Обновлять существующие библиотеки (npm update, npm upgrade)
- ❌ Удалять библиотеки (npm uninstall, npm remove)
- ❌ Изменять package.json или package-lock.json
- ❌ Выполнять любые команды управления зависимостями

## Процедура изменений
1. Предложить изменение с объяснением
2. Показать точный код/команду для выполнения
3. Дождаться явного согласия пользователя ("да", "согласен", "делай")
4. Только после согласия выполнять изменения

## Исключения
Никаких исключений. Всегда спрашивать разрешение.
