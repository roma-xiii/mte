# Бэктестер стратегий для алготрейдинга.

Нужно реализовать большой и сложный бэктестер. С следующей архитектурой

Python (Litestar + NautilusTrader) - backtester server
^
|
v
Tauri (Rust) - bridge
^
|
v
React (TypeScript) - UI

### User story
В бэктестере мы выбираем биржу (пока интересует только Bybit и Binance), Пара (выпадающий список с поиском), таймфрейм в выпадаещем списке, Диапазон теста.

Также есть возможность выбрать уже раннее загруженные котировки. Вместо настроек бирж, тф и пр.

Выбираем стратегию, вбиваем ее параметры.

Жмем старт. Команда через таури улетает на питон. Если выбрали ранее загруженные котировки, то тестер просто запускает выбранную стратегию на раннее загруженной истории.

Если запуск не по загруженной истории, то питон сервер качает историю, складывает в csv и добавляет в список достпных для тестов котировок.

В процессе теста я могу управлять скоростью подачи новых свечей боту. Стартовая скорость 1 бар в 1 секунду. Ползуноком я могу увеличивать скорость до 100 бар в секунду.

Также могу управлять процессом теста с помощью кнопок pause/resume. Или вообще остановить кнопкой Stop.

Должен быть график инструмента. Куда падают свечи и отрисоываеются входы и выходы. ТП и СЛ. Для графиков используем tradingview-lightweight

Также под графиком должен быть лог. Мне может понадобится отсылать сообщения из питон в инерфейс для отладки.

Помимо лога должна быть история сделок. Можно Лог и Сделки сделать перекулючаемыми с помощью табов.

Процесс запуска теста не должен зависить от окна интерфейса. Например, если его закрыли, тест должен продолжаться, а если открыли, в окно должен подгружаться весь лог и история и статусы.

Для интерфейса используем mantine-ui.
В репозитории уже есть какой то код по бэктестеру, но его можно удалить.
