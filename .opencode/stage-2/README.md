## Приёмка

- [ ] Локальный CSV: Start → paused → resume → Stop → новый Start без перезапуска процессов.
- [ ] Завершение всех баров → completed → новый Start; невалидный Start не удаляет прошлый результат.
- [ ] Ошибка загрузки/инициализации → failed с сообщением и cleanup → исправленный Start работает.
- [ ] Stop в loading, running, paused; остановка не выдаётся за completed и 100%.
- [ ] Stop/конец истории закрывают позиции, отменяют заявки и фиксируют финальные исполнения; нет дополнительных баров/входов.
- [ ] Скорости 1/10/100 подтверждаются сервером, отсутствует искусственное ограничение 10 бар/с. Сравнивать с допуском и отдельно от затрат стратегии; указывать фактически достигнутую скорость.
- [ ] После события paused история баров не растёт; смена скорости в paused не возобновляет тест.
- [ ] Закрытие окна/WS не меняет состояние прогона. Новый клиент восстанавливает running/paused/terminal, бары, позиции, сделки, полный лог и прогресс.
- [ ] Два клиента получают одинаковую историю, а не конкурируют за одну очередь; медленный подписчик не блокирует движок.
- [ ] Повторные/устаревшие команды и события не меняют новый прогон; snapshot + live не дают пропусков/дублей.
- [ ] Перезапуск Python даёт новый server_id и idle; UI не показывает старую сессию как действующую.
- [ ] Потеря ack/таймаут не провоцируют автоматический второй Start. Состояние уточняется через get_session.
- [ ] Сборки и тесты проходят. Неисправленные метрики отмечены отдельно и не объявляются достоверными.

Начальная граница приёмки — локальный CSV. Сетевая загрузка сохраняется и корректно обрабатывает отмену/ошибки; полноценное качество биржевых данных и каталог фьючерсов относятся к этапу данных.
