# Запуск тестера (Nautilus + Tauri)

Тестер состоит из двух процессов, которые запускаются отдельно в двух терминалах:

1. Python-сервер (Nautilus Trader) — WebSocket-бэкенд для бэктестов.
2. Десктоп-клиент (Tauri + React/Vite) — окна тестера.

Каждый блок команд ниже начинается из корня репозитория `mte`. Если выполняете блоки последовательно в одном терминале, сначала вернитесь в корень проекта.

## 1. Требования к окружению

- **Python 3.12** — Makefile создаёт venv с `uv venv --python 3.12`; `pyproject.toml` требует `>=3.12`.
- **uv** — используется для установки Python-зависимостей (`make install`). Конкретная версия uv проектом не фиксируется.
- **Node.js и npm** — frontend ставится через `npm ci` по `package-lock.json`. Конкретная версия Node проектом не фиксируется.
- **Rust (rustc/cargo)** — для сборки Tauri. Репозиторий фиксирует только edition 2021 в `Cargo.toml`, точные версии компилятора не заданы.
- **Инструменты сборки Tauri для macOS** — Xcode Command Line Tools (компилятор, системные библиотеки). Точные версии инструментов проект не фиксирует.

## 2. Первичная установка зависимостей

```bash
# Python-бэкенд: каталог nautilus
cd nautilus
make install            # создаёт .venv (uv venv --python 3.12) и выполняет uv sync
```

```bash
# Десктоп-клиент: каталог client-tauri
cd client-tauri
npm ci                  # установка frontend по package-lock.json
```

## 3. Запуск — два терминала

### Терминал 1: backend

```bash
cd nautilus
make run
```

Для разработки с hot-reload используйте `make run-dev` — это тот же сервер с флагом `--reload`, адрес и порт не меняются. Python-сервер пока запускается отдельным процессом.

### Терминал 2: desktop

```bash
cd client-tauri
npm run tauri dev
```

`npm run tauri dev` запускает Vite (порт 1420) и открывает главное окно Tauri.

## 4. Порты и адреса

- **8765** — Python-сервер, WebSocket по пути `/ws` (по умолчанию `127.0.0.1`).
- **1420** — Vite dev-сервер (`strictPort`, порт зафиксирован).

Rust-мост подключается по фиксированному адресу `ws://127.0.0.1:8765/ws`. Поэтому изменение только порта Python (например, `--port`) разорвёт подключение — приложение не переподключится к другому адресу. Смена адреса требует правки адреса в Rust-мосте и пересборки приложения. При совпадающем адресе клиент переподключается автоматически с задержкой ~2 с.

## 5. Окно тестера

Откройте **Backtest** с главного окна. Вверху экрана — статус соединения:

- «Python подключён» — соединение установлено, списки стратегий и данных загружаются автоматически.
- «Подключение к Python…» — клиент пытается подключиться.
- «Нет подключения к Python» — сервер недоступен.

Если Python не запущен: показывается жёлтое предупреждение «Сервер тестера недоступен», кнопка Start недоступна, бесконечного начального Loader нет. Запустите backend — клиент сам переподключится и запросит актуальные списки стратегий и файлов данных; перезапуск Tauri не нужен. Списки запрашиваются при каждом подключении и открытии окна Backtest.

Ошибки команд (invoke) показываются прямо в окне, а не только в консоли.

Не путайте `npm run dev` (только Vite в браузере) с desktop: обычный браузер не предоставляет Tauri API, поэтому состояние соединения, каталоги и команды доступны только в окне `npm run tauri dev`.

## 6. Проверки сборки

```bash
# Frontend: каталог client-tauri
cd client-tauri
npm run build           # tsc && vite build
```

```bash
# Rust: каталог client-tauri/src-tauri
cd client-tauri/src-tauri
cargo check --offline
```

`cargo check --offline` работает без сети и требует уже скачанных Rust-зависимостей в локальном кэше (`Cargo.lock` в репозитории есть). Это не установка с нуля: для первичного наполнения кэша нужен запуск с доступом к сети.

## 7. Короткий сценарий проверки на сохранённом CSV

1. Запустите backend и desktop (раздел 3).
2. Выберите **Use saved data** → `BTCUSDT-1d.csv` и стратегию **SMA Crossover** (`sma_crossover`).
3. Установите **Trade Size = 1**, **Order Type = market**, **Take Profit = 0**, **Stop Loss = 0**; начальный баланс оставьте 1 000 000. Сейчас Trade Size означает количество базового актива (для этого файла — 1 BTC), несмотря на подпись USD. Не оставляйте значение объёма 100 000 по умолчанию. Нажмите Start.
4. Ожидайте: получение готовности (ready), поток баров/свечей и завершение (complete) со статистикой в окне.

Это проверка пайплайна запуска: подключение, каталоги, запуск прогона. Корректность PnL и управление сессией (восстановление прогона, исправленная статистика, фьючерсные/маржинальные детали) будут доводиться следующими этапами и в этой версии не гарантированы.

## 8. Завершение и занятые порты

Для завершения работы нажмите `Ctrl+C` в терминалах backend и desktop. Окна Tauri также можно закрывать обычным способом. Остановка Python завершает процесс и теряет сессию в памяти; она не гарантирует закрытие позиций и формирование итогового отчёта. Политика завершения активного теста будет исправлена на следующих этапах.

Если порт 8765 или 1420 уже занят — это почти всегда означает работающий сервер или dev-процесс. Найдите процесс именно этого порта (например, `lsof -i :8765`) и решите, нужен ли он вам. Не завершайте все Python/Node-процессы скопом.
